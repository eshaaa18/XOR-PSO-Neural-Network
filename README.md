# XOR-PSO-Neural-Network
Project Overview
This project explores different techniques to solve the XOR problem using Neural Networks.
It includes:
Particle Swarm Optimization (PSO) trained MLP
Standard Backpropagation MLP
Hidden neuron comparison study

Implementations:

1️. PSO vs Backpropagation
File: pso_vs_backprop.py
Trains XOR using PSO
Compares with gradient backpropagation
Plots convergence graph

2.Hidden Neuron Comparison
File: mlp2.py
Model 1 → 2 hidden neurons
Model 2 → 4 hidden neurons
Compares convergence speed & loss
